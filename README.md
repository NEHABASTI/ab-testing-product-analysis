 A/B Testing Analysis for Product Conversion Optimization

This project analyzes an A/B testing experiment conducted to evaluate the impact of a new product design on user conversion rates.

## Objective
To compare user conversion behavior between the control group (old design) and treatment group (new design) and determine whether the difference is statistically significant.

## Key Steps
- Data exploration and preprocessing
- Conversion rate comparison between control and treatment groups
- Visualization of experiment results
- Statistical hypothesis testing using Z-test
- Product recommendations based on experiment outcomes

## Key Insights
- The treatment group showed slightly higher conversion rates than the control group
- However, the difference was not statistically significant (p > 0.05)
- More data may be required before making a final product rollout decision

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Statsmodels
